# 📅 SmartKakeibo - カレンダー家計簿アプリ

日々の収支を**月間カレンダー**上で直感的に確認・記録できる、シンプルで使いやすいモダン家計簿 Web アプリケーションです。
予算などの複雑な設定を省き、**「毎日の支出・収入の把握」**に特化しています。

---

## 📁 ファイル構成

```text
├── index.html              # アプリ構造・月間カレンダー・モーダル
├── style.css               # カレンダーグリッド・テーマ・レスポンシブデザイン
├── app.js                  # カレンダー描画エンジン・収支CRUD・グラフ分析・データ保存
└── google-apps-script.js   # Google スプレッドシート連携用 GAS スクリプト (setup / doPost / doGet)
```

---

## ✨ 主な機能

1. **🗓️ 直感的な月間カレンダービュー (メイン機能)**
   - 日付ごとのマスに**支出合計（赤）**と**収入合計（緑）**、件数をすっきり表示
   - カレンダーの日付マスをクリックするだけで、その日の**収支明細パネル**が即座に展開
   - 「この日に追加」ボタンから日付指定で素早く入力
   - 今日の日付をハイライト表示 ＆ 土日の色分け対応

2. **📊 シンプルな月間サマリー ＆ 週計**
   - 今月の総収入・総支出・収支差額（黒字/赤字）を上部に3カード表示
   - カレンダーの右端に**週計（行ごとの支出・収入・差額）**を常時表示。クリックでその週の全明細を確認可能
   - 貯蓄率のリアルタイム計算

3. **📝 収支の簡単記録 ＆ リアルタイム連携**
   - 支出 / 収入の切り替え
   - 金額クイック加算チップ（+100, +500, +1,000, +5,000, +1万）
   - カテゴリ・支払方法・メモ・固定費の簡単入力
   - 記録追加・編集・削除時にGoogleスプレッドシートへ自動同期

4. **🔍 収支明細一覧 ＆ 検索**
   - 日付順グループ化リスト
   - メモ・店名・カテゴリ名でのインクリメンタル検索
   - 収支種別や支払方法での絞り込み

5. **📈 統計 ＆ グラフ分析**
   - カテゴリ別支出シェア（ドーナツ円グラフ）
   - 支払方法の内訳割合
   - 過去6ヶ月間の収支推移比較バーチャート

6. **☁️ Googleスプレッドシート連携 (GAS)**
   - Google Apps Script (GAS) 経由でスプレッドシートと双方向同期
   - 収支の追加・編集・削除をスプレッドシートへ即時反映
   - アプリ内からワンクリックでGASスクリプトをコピー＆導入ガイド完備

7. **💾 データ管理・バックアップ**
   - ブラウザへの自動保存（LocalStorage）
   - **CSVエクスポート**（Excel等での閲覧用）
   - **JSONバックアップ・復元**
   - **ダークモード / ライトモード** 切替

## 🛠️ Build and Deployment

### ローカル開発環境

#### 前提条件
- モダンブラウザ（Chrome, Firefox, Safari, Edge など）
- ローカルサーバー（開発時は CORS エラー回避のため推奨）

#### セットアップ

```bash
# プロジェクトのクローン
git clone https://github.com/sena2127/ramen.git
cd ramen

# ローカルサーバーの起動
# Python 3
python3 -m http.server 8080

# Node.js
npx serve .
```

ブラウザで `http://localhost:8080` にアクセスしてください。

---

### 本番環境へのデプロイ

このアプリケーションは完全に静的なファイル（HTML/CSS/JS）で構成されているため、以下のサービスで簡単にデプロイできます。

#### 1. **GitHub Pages** （推奨・無料）

```bash
# リポジトリの設定
git remote add origin https://github.com/sena2127/ramen.git
git branch -M main
git push -u origin main
```

GitHub リポジトリの設定で、`Settings` → `Pages` → `Deploy from a branch` を選択し、`main` ブランチを指定。

#### 2. **Netlify** （無料・自動デプロイ）

```bash
# Netlifyにサインアップ後、以下のコマンド
npm install -g netlify-cli
netlify deploy --prod
```

#### 3. **Vercel** （無料・自動デプロイ）

```bash
npm install -g vercel
vercel --prod
```

#### 4. **自前サーバー**

すべてのファイル（`index.html`, `style.css`, `app.js`, `google-apps-script.js`）を Web サーバーの公開ディレクトリにアップロード。

---

### Google Apps Script（GAS）のセットアップ

Google スプレッドシートとの連携を有効にするには：

1. **Google シートの作成**
   - Google ドライブで新しいスプレッドシートを作成

2. **Apps Script エディタを開く**
   - `拡張機能` → `Apps Script`

3. **スクリプトをコピー**
   - アプリ内の `⚙️ 設定` → `📝 GAS スクリプト取得` からコードをコピー
   - またはこのリポジトリの `google-apps-script.js` の内容をコピー

4. **デプロイ**
   - スクリプトを保存
   - `デプロイ` → `新しいデプロイ` → タイプ「ウェブアプリ」を選択
   - 実行ユーザーとしてアクセス: `自分`
   - 次のユーザーとして実行: `自分`

5. **アプリに登録**
   - 生成されたウェブアプリ URL をアプリの `⚙️ 設定` → `スプレッドシート URL` に貼り付け
