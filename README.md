# 💰 SmartKakeibo - スマート家計簿アプリ

シンプルで使いやすく、日々の収支記録からグラフ分析・予算管理まで完結するモダンな家計簿 Web アプリケーションです。
HTML / CSS / JavaScript の3ファイル構成で軽量かつ依存レスに動作します。

---

## 📁 ファイル構成

```text
├── index.html   # アプリの骨格・UI構造・モーダル定義
├── style.css    # デザインシステム、テーマ（ライト/ダーク）、レスポンシブスタイル
└── app.js       # 状態管理、収支CRUD、集計・統計、Chart.js描画、CSV/JSON入出力
```

---

## ✨ 主な機能

1. **📊 概要ダッシュボード**
   - 今月の総収入・総支出・収支差額（黒字/赤字）・予算残高を瞬時に把握
   - カテゴリ別支出比率のインタラクティブ・ドーナツ円グラフ
   - トップ支出カテゴリのリアルタイムランキング表示

2. **📝 収支の簡単記録 & 編集**
   - 支出 / 収入のクイック切り替え
   - 金額クイック加算チップ（+100, +500, +1,000, +5,000, +1万）
   - カテゴリ選択（食費、日用品、住居費、光熱費、交通費、給与、副業など）
   - 支払方法（現金、クレジットカード、電子マネー/QR、銀行振込）
   - 固定費（家賃・光熱費・サブスク）フラグ設定

3. **🔍 収支明細一覧 & 絞り込み検索**
   - 日付別グループ表示（日ごとの小計支出・収入を自動計算）
   - キーワード検索（メモや店名でインクリメンタル検索）
   - 種別（支出/収入）、カテゴリ、支払方法での絞り込み
   - 日付順・金額順の並び替えソート

4. **📈 統計 & グラフ分析**
   - 過去6ヶ月間の収支推移バーチャート（収入 vs 支出バランス）
   - 今月の日別支出トレンド折れ線グラフ
   - 支払方法別（キャッシュレス vs 現金）の内訳比率グラフ

5. **🎯 予算管理**
   - 月間総予算の設定 & リアルタイム消化率プログレスバー
   - カテゴリ別個別予算の設定 & 予算オーバー警告アラート

6. **🏆 今月の振り返りレポート**
   - 月末の家計状況をA+〜Dのスコアで総合判定
   - 貯蓄率の算出 & 状況に応じたアドバイス表示
   - 目標達成時の紙吹雪（Confetti）アニメーション

7. **💾 データ管理 & バックアップ**
   - ブラウザ（LocalStorage）への自動データ永続化
   - **CSVエクスポート**: Excelやスプレッドシートで分析可能なCSV出力
   - **完全バックアップ (JSON)**: 予算や全履歴を含むバックアップの保存 & ワンクリック復元
   - **サンプルデータ投入**: 初めてでも直感的に動作を試せるリアルな初期データ生成
   - **ダークモード / ライトモード対応**

## 🚀 使い方

ブラウザで `index.html` を開くだけで、すぐに利用できます。
簡易ローカルサーバーで起動する場合:

```bash
# Pythonの場合
python3 -m http.server 8080

# または Node.jsの場合
npx serve .
```
