# 📅 SmartKakeibo - カレンダー家計簿アプリ

日々の収支を**月間カレンダー**上で直感的に確認・記録できる、シンプルで使いやすいモダン家計簿 Web アプリケーションです。
予算などの複雑な設定を省き、**「毎日の支出・収入の把握」**に特化しています。

---

## 📁 ファイル構成

```text
├── index.html              # アプリ構造・月間カレンダー・モーダル
├── style.css               # カレンダーグリッド・テーマ・レスポンシブデザイン
├── app.js                  # カレンダー描画エンジン・収支CRUD・グラフ分析・データ保存
└── google-apps-script.js   # Google スプレッドシート連携用 GAS スクリプト (setup / doPost / doGet)
```

---

## ✨ 主な機能

1. **🗓️ 直感的な月間カレンダービュー (メイン機能)**
   - 日付ごとのマスに**支出合計（赤）**と**収入合計（緑）**、件数をすっきり表示
   - カレンダーの日付マスをクリックするだけで、その日の**収支明細パネル**が即座に展開
   - 「この日に追加」ボタンから日付指定で素早く入力
   - 今日の日付をハイライト表示 ＆ 土日の色分け対応

2. **📊 シンプルな月間サマリー ＆ 週計**
   - 今月の総収入・総支出・収支差額（黒字/赤字）を上部に3カード表示
   - カレンダーの右端に**週計（行ごとの支出・収入・差額）**を常時表示。クリックでその週の全明細を確認可能
   - 貯蓄率のリアルタイム計算

3. **📝 収支の簡単記録 ＆ リアルタイム連携**
   - 支出 / 収入の切り替え
   - 金額クイック加算チップ（+100, +500, +1,000, +5,000, +1万）
   - カテゴリ・支払方法・メモ・固定費の簡単入力
   - 記録追加・編集・削除時にGoogleスプレッドシートへ自動同期

4. **🔍 収支明細一覧 ＆ 検索**
   - 日付順グループ化リスト
   - メモ・店名・カテゴリ名でのインクリメンタル検索
   - 収支種別や支払方法での絞り込み

5. **📈 統計 ＆ グラフ分析**
   - カテゴリ別支出シェア（ドーナツ円グラフ）
   - 支払方法の内訳割合
   - 過去6ヶ月間の収支推移比較バーチャート

6. **☁️ Googleスプレッドシート連携 (GAS)**
   - Google Apps Script (GAS) 経由でスプレッドシートと双方向同期
   - 収支の追加・編集・削除をスプレッドシートへ即時反映
   - アプリ内からワンクリックでGASスクリプトをコピー＆導入ガイド完備

7. **💾 データ管理・バックアップ**
   - ブラウザへの自動保存（LocalStorage）
   - **CSVエクスポート**（Excel等での閲覧用）
   - **JSONバックアップ・復元**
   - **ダークモード / ライトモード** 切替
